Fruit Snake Battle 🐍🍎

A browser-based Snake Battle game where you don't just eat fruit — you fight computer-controlled snakes for survival.

Eat fruit to grow, outmaneuver your opponents, and turn defeated snakes into food for the remaining players.

🧠 Game Mechanics

The game combines classic Snake mechanics with a simple battle-arena system.

Fruit

Eating normal fruit increases the snake's length and score.

Defeated Snakes

When a computer snake is eliminated, its body segments remain in the arena as collectible fruit.

This creates an additional strategic element: defeating an opponent can create a valuable food source for whoever survives.

Difficulty

Novice
Computer snakes are less aggressive and provide an easier introduction to the game.

Beginner
A balanced experience between challenge and accessibility.

Expert
Computer snakes behave more aggressively, creating a more challenging battle.

🚀 Running Locally

Clone the repository:

git clone https://github.com/YOUR-USERNAME/fruit-snake-battle.git

Enter the project:

cd fruit-snake-battle

Because this is a client-side HTML/CSS/JavaScript game, you can simply open index.html in a browser.

For a better development experience, you can also use a local development server such as VS Code/Zed with a static server extension or any simple HTTP server.
